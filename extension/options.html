以前の共通 Favorites

Favorites はスペースごとになりました。以前の全スペース共通の Favorites（ 件）は、移すまで全スペースに出ています。移すスペースを選んでください。

Arc から取り込む

Arc の ~/Library/Application Support/Arc/StorableSidebar.json を選ぶと、スペース・Favorites・ピン留め・フォルダを取り込みます。 ファイルを選ぶ画面で Cmd+Shift+G を押し、上の場所を貼り付けると開けます。 今あるものは消さず、足すだけです（同じ名前のスペースにはまとめ、同じ URL は飛ばします）。今日のタブは取り込みません。

Live Folders（GitHub）

レビュー依頼と自分の PR を、スペースの中のフォルダ「レビュー依頼」「自分の PR」に書き出します。 GitHub の fine-grained personal access token（Repository permissions の Pull requests を Read-only、ほかはなし）を入れてください。 見えるのは、トークンに許可したリポジトリの PR だけです。トークンはこのパソコンの中（chrome.storage.local）にだけ保存し、api.github.com 以外には送りません。

書き出しと読み込み

スペースのアイコンと色、分割のペア、閉じたフォルダ、アーカイブ、設定を JSON に書き出し、別の場所に入れたこの拡張へ読み込めます。 ピン留めや Favorites はブックマークにあるので、ここには含みません。GitHub のトークンも含みません。

Little Arc

ほかのアプリから開いたリンクを小窓で開く機能の設定と、判定のログは 別のページ にあります。
