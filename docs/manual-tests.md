# 手で確かめる項目

ドラッグ、ショートカット、ほかのアプリとの行き来は、セルフテストでは確かめられません。変更したあとは、関係するところをここから選んで確かめてください。

## サイドバー

| # | 手順 | 期待 |
| --- | --- | --- |
| S1 | Cmd+S を 2 回押す | サイドパネルが開いて、閉じる |
| S2 | サイドパネルを閉じた状態で、画面の左端にカーソルを当てる | ページの上にサイドバーが出る。外へカーソルを動かすと引っ込む |
| S3 | サイドパネルを開いた状態で、画面の左端にカーソルを当てる | 重ねて出すサイドバーは出ない |
| S4 | 今日のタブをピン留めの欄へドラッグ | ピン留めになる |
| S5 | ピン留めの行を、別の行の上半分・下半分・フォルダの真ん中へドラッグ | 前・後ろ・フォルダの中へ移る |
| S6 | 開いているピン留めの − を押す → 行を押す | タブだけ閉じる → 開き直す |
| S7 | 閉じているピン留めを今日のタブの行のあいだへドラッグ → Cmd+Z | 落とした位置にタブが開く → ピン留めに戻り、開いたタブは閉じる |
| S8 | 行の名前をダブルクリック | その場で名前を変えられる |
| S9 | 今日のタブを × で閉じる → Cmd+Z | 閉じてアーカイブに残る → 戻り、アーカイブからも消える |
| S10 | 仕切り線にカーソルを当てて Clear | 今日のタブがまとめてアーカイブされる（表示中のタブは残る） |

## スペース

| # | 手順 | 期待 |
| --- | --- | --- |
| P1 | 下端の ＋ でスペースを作る | 名前を入れられ、新しいスペースに切り替わる |
| P2 | サイドバーの上で 2 本指の横スワイプ | 隣のスペースへ切り替わり、そのスペースで最後に見ていたタブが出る |
| P3 | 今日のタブを下端のスペースの点へドラッグ | そのスペースへ移る |
| P4 | スペース名を右クリック →「アイコンを変更」 | 絵文字を選べる |

## Split View

| # | 手順 | 期待 |
| --- | --- | --- |
| V1 | 今日のタブを右クリック →「今のタブと分割表示」→ Cmd+Z | 今見ているタブの右に並んで分割 → 解ける |
| V2 | 分割の行をピン留めの欄へドラッグ | ペアとしてピン留めされる |
| V3 | ペアの − を押す → 行を押す | 2 つのタブが閉じる → 分割で開き直す |
| V4 | ペアを開いたまま Chrome を終了して起動し直す | 数秒後に分割に戻る |
| V5 | 保存したペアを今日のタブの欄へドラッグ | ピン留めから外れ、今日のタブに分割の行で出る |

## コマンドバー・Peek・URL のコピー

| # | 手順 | 期待 |
| --- | --- | --- |
| C1 | 普通のページで Cmd+T、何か入れて Enter | ページの上にコマンドバーが出て、選んだものが新しいタブで開く |
| C2 | Cmd+L | 今のタブの URL を変えるコマンドバーが出る |
| C3 | Cmd+Shift+C | URL がコピーされ、ページに通知が出る |
| C4 | リンクを Option+クリック | 浮いた小さなウィンドウで開く。ほかのウィンドウを押すと閉じる |
| C5 | Peek のウィンドウで Cmd+O | メインのウィンドウのタブになる |

## Little Arc

Chrome を既定のブラウザにしてから確かめます。

| # | 手順 | 期待 |
| --- | --- | --- |
| L1 | ほかのアプリ（チャットやメールなど）でリンクを押す | 小窓で開く |
| L2 | 小窓で Cmd+O | メインのウィンドウのタブになる |
| L3 | Chrome の中でリンクを新しいタブで開く | 普通のタブで開く（小窓にならない） |

判定の様子は、設定ページから開く「Little Arc のログと設定」で見られます。

## Live Folders

| # | 手順 | 期待 |
| --- | --- | --- |
| G1 | 設定ページでトークンを入れて保存 | 選んだスペースに「レビュー依頼」「自分の PR」ができ、PR が並ぶ |
| G2 | サイドバーでフォルダを見る | GitHub のアイコンで出る |
| G3 | PR を 1 つ開いた状態で「今すぐ更新」 | 行は開いたまま |
| G4 | 「トークンを消す」 | 2 つのフォルダと状態が消える |

## 書き出しと読み込み

| # | 手順 | 期待 |
| --- | --- | --- |
| B1 | 設定ページで「書き出す」 | JSON が保存される。中に GitHub のトークンがない |
| B2 | 別のフォルダから読み込んだこの拡張で「読み込む」 | スペースの色とアイコン、分割のペア、アーカイブが戻る |
